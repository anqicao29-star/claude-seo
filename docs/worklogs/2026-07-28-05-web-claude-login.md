## 大白话总结

以前网页只会告诉用户去终端运行 `claude auth login`，这对要直接分发给别人使用的产品不合理。

本次已经改成网页顶部的“登录 Claude（订阅）”按钮。用户点击后，工作台会调用本机已安装的 Claude CLI 打开 Claude 官方登录流程。账号、密码、验证码和令牌都由 Claude 官方页面及 Claude CLI 处理，本项目不接收、不保存这些凭据。

登录完成后，网页会自动检查登录状态，不需要用户手动刷新。旧会话里已经保存的“请去终端登录”提示也会自动改成新的网页登录说明。

## 本次完成内容

1. 网页顶部新增“登录 Claude（订阅）”按钮。
2. 点击按钮后启动 Claude 官方订阅登录流程。
3. 登录期间按钮显示“等待登录……”。
4. 网页每两秒自动检查一次状态，登录成功后立即启用文章创作。
5. 文章模式未登录时，输入框和聊天提示都改为引导用户点击网页按钮。
6. 历史会话中旧的终端登录提示会在显示时自动更新。
7. 后台只负责启动官方 CLI，不读取登录输出，也不处理用户凭据。
8. 增加登录模式白名单，拒绝网页传入未知登录方式。
9. 后台服务已经重启，新页面立即生效。

## 为什么采用这种方式

Claude Code 当前的官方登录方式不只有一种：

- Claude.ai 订阅登录，适合已有 Pro 或 Max 订阅的普通用户。
- Anthropic Console 登录，使用 API 计费。
- 企业环境还可以配置 SSO、Amazon Bedrock 或 Google Vertex AI。

当前产品目标是“发给别人后在本机登录自己的 Codex 和 Claude 就能用”，因此界面先只保留最容易理解的订阅登录按钮。后台已经为 Console 模式保留入口，但暂时不增加额外选项，避免把界面做复杂。
