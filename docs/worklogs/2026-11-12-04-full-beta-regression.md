## 商业登录边界

OpenAI 官方文档说明，本地或开源应用可以继续使用现有 Codex app-server 认证，但旧认证从未允许商业或托管服务；官方建议商业场景迁移到 Sign in with ChatGPT。当前产品直接调用用户本机 Codex CLI，不完全等同于 app-server，但官方资料不足以让我们承诺“订阅登录可直接用于第三方商业分发”。

Anthropic 官方资料把 Free/Pro/Max 和 Claude Code 归入个人 Consumer Terms；商业使用对应 Claude for Work 或 API 商业条款。个人订阅确实能在本机 Claude Code 中工作，但不能据此承诺第三方商业产品的封装合规。

所以技术上两种订阅登录都已经跑通，商业对外版本仍应采用官方商业认证/API 方案，或取得厂商书面确认。
