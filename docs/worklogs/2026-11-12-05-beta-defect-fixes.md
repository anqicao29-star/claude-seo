## 大白话总结

这次把上一轮测试抓出的三个实际问题都修了。

第一，用户取消任务或任务超时时，系统现在不只关掉 Codex/Claude 主进程，还会找到它启动的所有子进程一起关掉。专门构造了一个“子进程自己脱离父进程”的难测场景，修复后父进程和子进程都能退出，不会继续在后台偷偷运行。

第二，页面现在能分清“没有安装”和“已经安装但没有登录”。没有安装 Claude 时，会明确让用户先安装，不再叫用户点击一个根本不存在的登录按钮；Codex 也做了同样处理。

第三，启动器不再只看电脑里有没有 `python3`，而是确认版本至少为 3.10。当前这台电脑自带的 Python 是 3.9，启动器已经能自动找到 Homebrew Python 3.12 并用它启动服务。
