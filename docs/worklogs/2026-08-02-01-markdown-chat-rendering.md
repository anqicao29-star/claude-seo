## 大白话总结

以前 AI 返回 `# 标题`、`**粗体**`、列表或表格时，网页只是把这些符号原样显示，所以看起来像普通文本。

现在 AI 的回复会默认按 Markdown 排版：标题会有层级，粗体会加粗，列表会分项，表格会显示成表格，代码会放进代码框。用户自己发送的内容仍按原文显示，不会被误当成 Markdown。

## 本次做了什么

1. 新增一个随本地工作台一起分发的 Markdown 渲染器，不依赖 CDN 和外部网站。
2. 已支持标题、段落、粗体、斜体、删除线、有序/无序列表、任务勾选框、引用、分隔线、链接、表格、行内代码和代码块。
3. AI 流式返回过程中会立即按 Markdown 更新，不用等任务彻底结束。
4. 历史对话重新打开后，也会自动按 Markdown 展示。
5. 增加适配明暗主题的 Markdown 样式和横向滚动表格。
6. 安全处理模型输出：原始 HTML 不会执行，危险的 `javascript:` 链接不会变成可点击链接。
