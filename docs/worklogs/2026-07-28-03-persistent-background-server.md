## 大白话总结

之前虽然提供了启动器，但服务仍然依附在启动它的终端或开发会话上。终端关闭、Codex 对话结束或运行工具被回收后，后台也会一起退出。浏览器再次访问 `localhost:7777` 时，就会显示“拒绝连接”。

这次把启动方式改成了真正的后台常驻：

- 双击启动器后，服务会独立在后台运行。
- 启动窗口关闭后，网页仍能继续使用。
- 重复启动不会开多个服务，而是直接复用已有服务。
- 用户可以检查服务是否运行，也可以安全停止。

## 本次完成内容

1. `run_workbench.py` 默认改为后台启动。
2. macOS、Linux、Windows 启动器自动获得后台运行能力，无需分别重写。
3. 增加状态检查：

```bash
python3 run_workbench.py --status
```

4. 增加安全停止：

```bash
python3 run_workbench.py --stop
```

5. 每个端口使用独立 PID 文件：

`~/.cache/claude-seo/workbench-7777.pid`

6. 后台日志保存到：

`~/.cache/claude-seo/workbench-7777.log`

7. 停止前会检查端口上的服务是否属于当前项目，避免误杀其他程序。
8. 端口已被当前工作台占用时，重复启动只会打开现有地址。
9. 使用说明增加后台运行、状态检查和停止方法。
