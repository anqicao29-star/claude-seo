## 第 1 阶段：国内可人工交付的最小闭环

- [ ] **CORE-01｜统一项目数据模型**：建立 Project、Prompt、Content、Publication、Check、Evidence、Report 七类基础记录。
- [ ] **DOM-01｜企业知识库**：保存企业事实、资质、案例、禁用表述、证据来源和更新时间，并检查信息冲突。
- [ ] **DOM-02｜国内信源诊断**：保存 AI 原始回答，识别品牌、竞品、引用来源、渠道缺口、风险和成本区间。
- [ ] **DOM-03｜多渠道内容包**：从同一可信事实生成官网、新闻/行业媒体、自媒体或问答等至少三种独立版本，并做一致性和合规检查。
- [ ] **DOM-04｜发布任务中心**：管理客户、内容、渠道、费用、状态和人工确认，支持 CSV/XLSX 导入导出。
- [ ] **DOM-05｜发布结果导入**：批量导入发布 URL、日期、截图、供应商订单号和失败原因。
- [ ] **DOM-06｜发布后验证与证据**：检查页面可访问性、内容一致性、索引条件、品牌提及和引用，并保存时间、原始回答、URL 与截图。
- [ ] **DOM-07｜客户报告**：输出发布清单、收录/提及/引用结果、前后对比、失败项和下一步，先支持 Markdown，随后补 PDF/XLSX。

完成标准：能为一个真实企业建知识库、找信源缺口、产出三种渠道内容、导出发布任务、导回 URL、保存证据，并给客户一份看得懂的报告。第一版允许人工发布，不做自动下单。

## 第 2 阶段：海外网站发布与验证闭环

- [ ] **OVER-01｜安全写入本地内容项目**：将文章写入指定 Markdown、MDX 或代码目录，写前显示 Diff，支持确认、备份和撤销。
- [ ] **OVER-02｜WordPress 草稿发布**：连接用户自己的 WordPress，只创建草稿，发布前保留人工确认。
- [ ] **OVER-03｜站内 SEO 发布辅助**：生成并校验标题、Meta Description、Slug、Canonical、Schema、内部链接、锚文本和 Sitemap 更新建议。
- [ ] **OVER-04｜发布后索引工作流**：检查页面状态和基础索引条件，接入 GSC、Bing Webmaster 与 IndexNow 的提交和结果回收流程。

完成标准：一篇文章可以安全进入本地网站或 WordPress 草稿，发布前可审查，发布后能检查页面和索引状态。

- [ ] **MON-01｜AI 可见度历史监测**：按平台、提示词、品牌和竞品保存原始回答、提及、情感、引用和人工复核结果。

- [ ] **DESKTOP-P1-01｜正式桌面分发**：API 凭据安全存储、数据备份/恢复/导出，以及 macOS 签名、公证和 DMG 分发。

## 明确暂缓，不作为开发待办

- 自建大规模媒体采购网络或同时接入大量供应商。
- 自动登录几十个自媒体账号批量发布。
- “7 天霸榜”“全平台前三”等无法保证的排名承诺。
- 把发布数量直接当作 GEO 效果，或制造虚假案例、专家、数据和品牌提及。
- 把媒体采购成本放进无限量订阅。
- OEM、贴牌和代理商充值体系。
- 任何破坏本地单机、用户授权和过程可审计原则的功能。

## 启动规则

1. 默认只推进第 0 阶段。
2. 用户明确说“开始国内闭环”后，再启动第 1 阶段，并优先做 `CORE-01`、`DOM-01`、`DOM-02`。
3. 用户明确说“开始海外发布”后，再启动第 2 阶段。
4. 第 3 阶段必须有真实客户数据或明确客户需求后再排期。
5. 每次工作继续生成工作日志，用大白话说明做了什么、验证结果和距离封测还有多久。
